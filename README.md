# 🍔 PRANISHA Food Delivery App

## 📌 About
This is a demo food delivery application built using Java Swing.  
It simulates basic features of real-world apps like Swiggy/Zomato for learning purposes.

## 🚀 Features
- Login / Signup
- Splash Screen Animation
- Food Categories (Pizza, Burger, etc)
- Add to Cart
- Payment UI (UPI/Card)
- Order Tracking

## 🛠 Tech Used
- Java Swing
- MySQL

## ⚠ Note
This is a demo project created for educational purposes only.  
No real payments or deliveries are performed.
